# 生命方程式 - 前端

健康咨询和医疗预约系统前端代码

## 技术栈

Vue 3 + Vite + Element Plus

## 推荐 IDE

[VS Code](https://code.visualstudio.com/) + [Vue (Official)](https://marketplace.visualstudio.com/items?itemName=Vue.volar)

## 项目启动

```sh
npm install
```

### 开发模式（热更新）

```sh
npm run dev
```

### 生产构建

```sh
npm run build
```
